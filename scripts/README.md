# Scripts

This directory is reserved for optional helper scripts (e.g., a connect/disconnect wrapper or a connection-verification check).

None are included yet — see [CONTRIBUTING.md](../CONTRIBUTING.md) if you'd like to add one. Any script added here should:

- Avoid hardcoding server addresses, credentials, or paths specific to one provider
- Read configuration/credential paths from arguments or environment variables, not embed them
- Be tested in an authorized lab environment before submission
