# Contributing

Contributions that improve clarity, fix inaccuracies, or expand the troubleshooting/documentation are welcome.

## How to Contribute

1. **Fork** this repository
2. **Create a branch** for your change: `git checkout -b docs/improve-troubleshooting`
3. **Make your changes** — documentation improvements, corrected commands, additional troubleshooting cases, etc.
4. **Test any commands** you add or change in an authorized lab environment before submitting — don't propose untested commands
5. **Submit a pull request** with a clear description of what changed and why

## Guidelines

- Keep documentation beginner-friendly and accurate
- Never include real credentials, keys, certificates, or provider-specific secrets in any file
- Stay within the ethical scope described in [SECURITY.md](SECURITY.md) — no credential harvesting, bypass techniques, or exploitation content
- Match the existing structure and tone where possible

Thanks for helping improve this guide!
